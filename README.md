## 📂 What I Build

I'm on a mission to **turn passion into products** — from frontend elegance to backend power. My focus: **large-scale features and real-time communication systems**.

#### ⚡ Featured Work

| System | What I Built |
|--------|--------------|
| 🤖 **MCP Servers** | Built Model Context Protocol servers connecting AI agents to real product data & tools |
| 📡 **Channels System** | Real-time messaging channels with live updates, presence & role-based access |
| 📞 **Calls System** | End-to-end call infrastructure — signaling, state handling & call lifecycle management |
| 🧵 **Queue Engine** | Robust queue system for background jobs, retries & high-throughput task processing |

#### 🚀 Career Vision

While I work with **MERN**, my ambition goes beyond the stack.
I don't want to be a "React dev" or "Angular guy" —
I aim to be a **true Software Engineer** who solves problems, not just writes code.

> 🧠 I build complex systems (with microservices!) — solo, under pressure, like a beast.
> No bug survives. No system overwhelms.

#### ⚙️ Engineering Philosophy

I've shipped **large features end-to-end** — from designing the data model to handling real-time edge cases in production.
